🎤 Speech·Text

Speak — and watch your words type themselves.

A real-time Speech-to-Text web app built as a Project. No typing needed, just talk!

✨ What it does

🎙️ Converts your voice to text instantly
📋 Copy, 💾 Save as .txt, or 🗑️ Clear your transcript
📊 Live word, character & sentence count
🎨 Clean GenZ-style UI with animations


🚀 How to Run

Open the folder in VS Code
Run the project,it is as simple
Click the mic 🎤, allow access, and start talking!


⚠️ Use Google Chrome or Edge only. Won't work on Firefox.


🛠️ Built With
HTML · CSS · JavaScript · Web Speech API
